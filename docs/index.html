So funktioniert das Spiel

Das RaidClipPlugin verwaltet deinen Spielstand. Die Twitch Extension zeigt bestätigte Daten an und übermittelt freigeschaltete Spielaktionen. Spielen setzt ein verbundenes, spielbereites Plugin voraus; der Stream muss dafür nicht live sein.

Welche Aktionen verfügbar sind, hängt von der freigegebenen Version und der Plugin-Konfiguration ab.
