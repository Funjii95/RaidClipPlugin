# Plugin 2.8.10 / Windows 0.9.9 – Gnade der Morgenflut

- Neues mythisches Heiler-Set mit elf Teilen: Helm, Brust, Handschuhe, Stiefel, Waffe, zwei Ringe, Amulett, Gürtel und zwei Trinkets.
- Alle Teile sind ab Level 1 tragbar und über die vollständige Admin-Setvergabe sowie im bestehenden Beutepool mythischer Dungeons erhältlich. Dungeon-Zugangsvoraussetzungen bleiben bestehen.
- Kumulative Setboni: +25 % Heilwirkung (2), +25 % maximales Leben (4), +15 Prozentpunkte kritische Heilchance (6), weitere +35 % Heilwirkung (8), Überheilungsschilde (9).
- Bei elf Teilen löst aktive Gruppenheilung zusätzlich eine Heilwelle für alle anderen lebenden Mitglieder aus: 75 % Grundheilung, acht Sekunden Abklingzeit, keine Kettenauslösung.
- Windows 0.9.9 enthält elf individuelle weiß-goldene Bilder und mythische Seltenheitsrahmen.
- Enthält die Serverkorrektur zur Freigabe authentifizierter Muschelöffnungsaktionen; die Serversperre wurde bereits separat behoben.

Für das neue Set sowohl Plugin 2.8.10 als auch Windows 0.9.9 aktualisieren. Spielstände bleiben erhalten.
